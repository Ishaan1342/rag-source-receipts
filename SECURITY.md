# Security

Only the current main branch is maintained during the MVP phase. This is not
a production security guarantee or a promised response SLA.

Please do not post exploitable vulnerabilities, credentials or private data
in public issues. Use GitHub's **Security → Report a vulnerability** if private
reporting is available. If it is unavailable, use an established private channel
to the maintainer and request a secure disclosure route before sending details.

Include the affected version, a minimal synthetic reproduction, impact and any
mitigation you have verified. Do not test against systems you do not control.
